# Social Network System Design (VKontakte REST API)

Репозиторий создан в рамках выполнения Домашнего задания №2 по курсу **System Design** Владимира Балунова.

## 📌 Описание проекта
В рамках задания спроектировано REST API для ключевого функционала социальной сети ВКонтакте. Архитектура построена с учетом принципов REST, масштабируемости и эффективной работы при высоких нагрузках (Highload).

## 🛠 Реализованный функционал (Endpoints)
Спецификация API включает в себя следующие возможности:
* **Пользователи и Друзья:** Просмотр анкет, отправка/принятие заявок, удаление из друзей с поддержкой пагинации.
* **Стена и Публикации:** Публикация постов с прикреплением медиафайлов, просмотр стены пользователя.
* **Загрузка медиа:** Выделенный независимый эндпоинт для загрузки бинарных файлов (изображения/видео).
* **Лента новостей:** Оптимизированная домашняя лента с пагинацией на основе курсоров (`start_from`/`next_from`) для исключения дубликатов при динамическом скролле.
* **Мессенджер:** Просмотр списка чатов, отправка сообщений и чтение истории переписки.

## 🗂 Структура репозитория
* `/api/rest_api.yml` — Спецификация OpenAPI 3.0 (Swagger)

## 🚀 Как открыть и протестировать API
1. Скопируйте содержимое файла `api/rest_api.yml`.
2. Перейдите в [Swagger Editor](https://swagger.io) или Swagger Studio.
3. Вставьте код в редактор для интерактивного просмотра документации.
